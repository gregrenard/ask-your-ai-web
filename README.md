# Ask your AI (draft)

Static draft of the Ask your AI landing page, a Freedom.AI Lab creation. Preview: https://gregrenard.github.io/ask-your-ai-web/

The page is marked noindex and its data is simulated: nothing is crawled, charged or sent. The page carries its own Ask your AI box, built with the same engine as the product; `ask-your-ai.md` is the facts brief that box points assistants to, and `llms.txt` is the index for crawlers.
